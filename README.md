## About

I'm a freelance developer from Egypt and the founder of **IMDEV**. I build web apps, Android apps, and the backends behind them, with a focus on clean UI, smooth animation, and Arabic-first products that work well in RTL.

- Front-end with **React, Next.js and TypeScript**
- Android with **Kotlin and Jetpack Compose**, cross-platform with **Flutter**
- APIs with **Node.js, Express and MongoDB**, plus **Firebase, Supabase and PostgreSQL**
- Exploring **AI, LLM APIs and agents**
